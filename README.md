# 🏏 IPL 2025 Player & Team Management (Python)

## 📌 Task Overview
This Python Task manages **IPL 2025 Teams and Players** using Object-Oriented Programming.  
Each player has the following attributes:
- Jersey Number
- Name
- Runs
- Wickets
- Team Name

The Task includes **getter & setter methods** for each attribute, and provides features to search and filter players.

---

## ⚡ Features
✅ Store team and player data in a structured way  
✅ Display batsmen who scored **more than 1000 runs**  
✅ Display bowlers who took **more than 20 wickets**  
✅ Display all players whose name contains the letter **'r'**  
✅ Support for multiple teams (RCB, PBK, MI, GT …)
